# 繰り返しタスクの実走記録

## 記録の境界

- 開始時のアプリ: `e3752aa`。仕様初稿: `716a249`。既存テスト9件は成功し、型チェックとLintも成功した。
- ユーザーからの依頼は「mergeしながら全て書き切ってください」。未決の入力境界はCodexが設計案として補完し、検証してからマージする。
- 実装・仕様整理はCodexが担当する。リポジトリに既設のAI Reviewワークフローの結果を、別のレビューとして記録する。手動の役割切替と、独立したエージェントの実行を区別する。
- 並列ワーカーによる速度比較や、未実施の対照実験は実績として扱わない。
- トークン数・費用を取得できない工程はnullとする。費用の上限と実測を混同しない。
